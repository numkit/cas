# План старта M0: вертикальный срез (обсуждение 2026-09-06)

Статус: M0 в работе. Скелет + BigInt готовы (коммит dc5224e).

## Ключевая идея

Не строить C0 целиком, а провести одну задачу через весь конвейер:
`∫ dx/(x²+1)` от выражения до доказанного ответа. Каждый элемент несущей
конструкции строится в минимальном виде и живёт вечно. Демо-цель посерьёзнее:
`∫ dx/(x⁴+1)` — комплексно-сопряжённые корни, где Риоро обязан дать чистый
вещественный арктангенс вместо комплексных логарифмов (витрина осей
«Качество» и «Доверие» плана на первой же неделе математики).

## Правки плана v0.4 → v0.5 (вызванные «чистым C++» и Numkit)

- D1: C++17 вместо C++20/23 (контракт интеграции).
- D4/D7: FLINT полностью выпадает → собственные слои (`BigInt` → `Q[x]` →
  позже интервальные шары) за фасадами. Пункт о лицензии FLINT в §11 снят.
- D9: однопоточный таймбоксированный каскад; потоки — compile-time опция
  после C1.
- C0 делится на C0a (DAG, числовой слой, полиалгебра, дифференциатор,
  гейт) и C0b (E-graph — отложен до C2; на старте тривиальный выбор
  кандидата с минимальным leaf count).
- Discrimination net Rubi — статические дата-таблицы, не генерация кода
  (бюджет размера WASM). Закрывает один из открытых вопросов §11.

## Порядок работ и статус

1. ✅ Скелет: CMake C++17, gtest через FetchContent, VS 2022, Release+Debug.
2. ✅ `BigInt`: u64-лимбы, знак-модуль, Кнут D на 32-битных разрядах
   (переносимо, без `__int128`/интринсиков), gcd, floor-сдвиги, строки.
   Три слоя тестов + 500k-фаззинг против Python-оракула при разработке.
3. ✅ `Rational` — канонические дроби поверх BigInt. Ключевое решение:
   инварианты (знаменатель > 0, НОД = 1, ноль = 0/1) enforced в единственной
   точке — конструкторе (p, q); вся арифметика проходит через него, поэтому
   любое Rational канонично по построению. Равенство тогда — это прямое
   сравнение пар. Оракул — fractions.Fraction (26 фиксированных векторов) +
   field-аксиомы на 20k итераций + int64-cross-check.
4. ⬜ `Expr` DAG + hash-consing + канонический конструктор + принтер.
5. ⬜ Дифференциатор по DAG.
6. ⬜ `Z[x]`/`Q[x]`: content/primitive, gcd (псевдоделения), squarefree,
   субрезультантный PRS, результант.
7. ⬜ Эрмит → Трагер → Риоро (срез).
8. ⬜ Гейт Tier-1 + property-тесты 10k случайных рациональных функций.

## Решения недели 1 (потом не переиграть)

- Канонизация в конструкторе — единственный контракт всего выше:
  авто-упрощение (`x·1→x`), сортировка детей AC-операторов, числовое
  сворачивание. Детерминизм важнее качества формы; качество — потом
  E-graph'ом (C0b/C2).
- Владелец интернера — `Ctx`, никаких глобальных таблиц (потоки, снапшоты).
- Бюджет/отмена с первого дня: каждый алгоритм принимает `Budget&`.
- Парсер отложен: тесты строят выражения кодом.

## Definition of Done среза

Property-тест: 10 000 случайных рациональных функций → интеграл →
`D(F) − f ≡ 0` символьно → 100% `PROVED_SYMBOLIC`. Это заготовка будущего
CI-корпуса §7.
