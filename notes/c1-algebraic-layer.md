# C1: слой алгебраических чисел и полный Трагер (старт 2026-09-06)

Цель C1 — довести рациональное ядро до 100% охвата: интеграл ЛЮБОЙ
рациональной функции, лог-часть через Rothstein–Trager без факторизации
знаменателя, вычеты — корни результанта res(A − tS′, S), т.е.
алгебраические числа.

## Дорожная карта слоя

1. ✅ Изоляция вещественных корней (poly/sturm): последовательность
   Штурма, коши-граница, изоляция бисекцией, уточнение. Тонкость,
   пойманная тестами до первого зелёного прогона: подсчёт вариаций
   знаков с пропуском нулей имеет ПОЛУОТКРЫТУЮ семантику (a, b] —
   конечные точки могут быть корнями. Изолятор несёт флаг «корень в
   hi», уточнение выбирает половину подсчётом Штурма, а не сменой
   знака (исходный p может иметь корни чётной кратности — знак меняет
   только бесквадратная часть!).
   Оракул: Durand-Kerner на Python (18 векторов), property: 3000
   случайных (дизъюнктность, ровно один корень, знакопеременность
   бесквадратной части), 2000 произведений известных рациональных
   корней (каждый изолирован).
2. ✅ `Budget` (core/budget.hpp) — отменяемость с первого дня (решение
   M0, теперь реально в коде; трединг в алгоритмы — по мере роста).
3. ✅ `Algebraic` (poly/algebraic): число = (моничный бесквадратный
   полином, изолирующий интервал); рациональные канонизированы в
   линейную форму x − r с точечным интервалом. Точное сравнение:
   сначала gcd полиномов — если оба числа лежат среди корней gcd
   (проверка счётом Штурма строго внутри интервала), сравниваем корни
   одного полинома (пересечение с одним корнем ⇒ равенство); иначе
   числа доказуемо различны — уточнение до разделения. Точные
   рациональные против открытых интервалов — через eval в точке и
   уточнение.
   Два бага пойманы тестами до коммита: (а) sign() считал 0 корнем
   числа, когда 0 — КОНЕЦ интервала (корень на границе не есть число);
   (б) refineRoot может вернуть точный интервал при попадании
   бисекции в рациональный корень — Algebraic обязан тогда
   нормализоваться в линейную форму, иначе инвариант
   «exact ⟺ рациональное» ломается и счёт Штурма получает
   вырожденный интервал (Debug-ассерт поймал).
4. ✅ Арифметика факторкольца Q[t]/(c) (poly/modcpoly) — вместо
   изначально планировавшейся полной Q̄-арифметики через результанты:
   критический путь Трагера — модульные вычисления в Q[t]/(c), а не
   поле алгебраических чисел (решение зафиксировано при планировании;
   результант уже берётся интерполяцией, см. промежуточный итог ниже).
   ModCRing: add/sub/mul/neg/inv/div по модулю неприводимого c
   (линейный c вырождается в Q — единый код); ModCPoly: плотные
   многочлены над этим полем, деление, монический gcd (Евкид).
   UPoly::invMod и operator% подняты в публичный API из ratint
   (дедупликация). Тонкость дизайна, пойманная Debug-ассертом и
   крашем в Release: безринг-ноль (default ModCPoly) обязан быть
   «нулём любого кольца» — операции обязаны брать кольцо с той
   стороны, где оно есть; ассерт в свободной функции не имел доступа
   к privates и молча выпадал в Release (NDEBUG вырезал выражение
   целиком) — проверка перенесена в private static член.
   Тесты: 30 векторов Python-оракула (два модуля: t²−2, t²+t+1;
   сложение/умножение/обратный), вырожденный линейный модуль,
   полевые аксиомы 3000 итераций (t²+1), кольцевые инварианты и
   divMod-тождество 2000 итераций, фиксированный gcd над Q(i).
5. ✅ Квадратичные вычеты через модульный Трагер (ratint): второй
   выметающий проход по результанту остатка — рациональные корни
   (включая нулевые: балластные полюса выбрасываются редукцией дроби
   по gcd числителя и знаменателя) уходят группированными логарифмами;
   если нерациональный остаток — ровно одна неприводимая квадратика
   c = t² + pt + q (для deg 2 «неприводимость ⟺ нет рационального
   корня» — факторизация не нужна), то v = gcd(A − tS′, S) над
   Q[t]/(c) через ModCPoly, коэффициенты v = A(x) + t·B(x), и пара
   сопряжённых вычетов даёт:
   - D = p²−4q > 0 (вещественная пара): α·log(A+αB) + ᾱ·log(A+ᾱB),
     α = u ± √D/2 — коэффициенты через Pow(d, 1/2), RootOf НЕ нужен;
   - D < 0 (комплексная пара): u·log(W) + √(−D)·atan(X/Y),
     X = A+uB, Y = wB, W = X²+w²B² — вещественная форма с √(−D).
   Ключевой факт: сумма по сопряжённым РАЦИОНАЛЬНА как производная —
   сертификат остаётся в Q(x), кольцо нужно только для вычисления v.
   ∫dx/(x²+2) = (√2/2)·atan(x/√2), ∫dx/(x²−2) = (√2/4)(log(x−√2) −
   log(x+√2)) — обе раньше были Unevaluated. Покрытие: ЛЮБАЯ
   квадратичная фактор-часть знаменателя с любым дискриминантом
   (DoD 2000 случайных). Пойманные до коммита баги: масштаб аргумента
   atan (2w вместо w), чтение p,q из немоничного squarefreePart,
   снапшот производной до редукции знаменателя (v вырождался в
   константу) — все по одному на каждую итерацию отладки, гейт
   каждый раз отказывался сертифицировать неверную форму.
   Полная Q̄-арифметика через результанты — отложена (Риобо/предположения).
6. ✅ Expr: RootOf-атомы + Цассенхаус + Трагер степеней ≥ 3 (все
   подпункты 6a/6b/6c-1/6c-2 закрыты; см. сессионные записи ниже).
   6a. ✅ F_p[x] и факторизация над F_p (poly/fppoly): плотные
   полиномы над F_p (p < 2³¹, u64-арифметика), divMod/gcd,
   powMod с BigInt-показателем (экспоненты масштаба p^d), полная
   факторизация: бесквадратная часть → distinct-degree (x^(p^d) − x)
   → Cantor–Zassenhaus равностепенного расщепления
   ((p^d−1)/2-степени), детерминированный PRNG.
   Верификация без внешнего оракула (sympy нет): реконструкция
   произведения + ферма-критерий неприводимости каждого фактора
   (x^(p^d) ≡ x mod g и gcd(x^(p^(d/q))−x, g) = 1 для простых q|d) —
   полное доказательство корректности разложения, не зависящее от
   алгоритма. Классика: x⁵−1 mod 3, x⁷−x mod 7 (7 линейных),
   неприводимый кубик; property 500 случайных (deg ≤ 7, p ∈ {7, 101})
   и 60 собранных из известных неприводимых.
   Урок теста: факторизация монична — сравнивать с моничным
   ассоциатом бесквадратной части (ловушка: деление на lc, не на
   lc·x^deg).
   6b. ✅ Поднятие Гензеля + реконструкция → факторизация Q[t]
   (полностью закрыта в сессиях 2026-09-07/08).
   6c. ✅ RootOf-атомы в Expr (таблица полиномов в Ctx, aux-id) +
   Трагер для неприводимых c степеней ≥ 3 (сертификат — след

   6c-1. ✅ RootOf-атом (2026-09-09): NodeKind::RootOf, таблица
   RootOfDesc в Ctx (полином как vector<Rational> — core НЕ зависит от
   poly-слоя), монизация при вводе, интернинг через nodeId-маппинг

   индекс таблицы; поймано тестом интернинга). compare: лексикографика
   по коэффициентам, затем индекс корня; печать RootOf(p, i);
   дифференцирование — нуль (атом-константа). Тесты: интернинг,
   монизация (2x²−4 ≡ x²−2 → один узел), печать, дифференцирование,
   полный порядок, 2000-итерационный property. 96 тестов зелёные.
   6c-2. ✅ Трагер над RootOf (2026-09-09). Математика: вклад
   Σᵢ αᵢ·log v(x,αᵢ) имеет РАЦИОНАЛЬНУЮ производную = полевой след
   Tr(t·v′·v⁻¹) в Q[t]/(c); след раскрывается через суммы Ньютона
   s_k = −Σ c_{d−i}s_{k−i} − k·c_{d−k} (первая версия формулы
   теряла множитель k и путала индексы — на z³−2 сошлось случайно,
   на z³+3z+5 дала s₂=−3 вместо −6; поймано trace-сертификатом).
   v = gcd(A − tS′, S) над полем имеет степень 1 на кубиках —
   это КОРРЕКТНО: v захватывает полюс с вычетом ≡ t, а вычисление
   v(x, σᵢ(t)) по сопряжению даёт факторы остальных полюсов.
   Сертификат: точная рациональная проверка тождества
   Tr = leftN/leftD в bound+1 рациональных точках (доказательство
   интерполяцией); при успехе subsumes арифметический гейт (гейт не
   видит RootOf-атомы — флаг gateProven). Ограничения ветки: ровно
   ОДИН неприводимый фактор степени ≥ 3 (несколько — Norm-вычитание
   не реализовано, honest Unevaluated). Флагманы: ∫dx/(x³+2),
   ∫dx/(x⁴+1), ∫dx/(x³+3x+5) — PROVED с RootOf-атомами; property
   на случайных неприводимых кубиках. 97 тестов зелёные.

## Промежуточный итог: Трагер для рациональных вычетов (2026-09-07)

`resultantT(P, Q, M)` = res_x(P − t·Q, M) — интерполяцией по t = 0..deg M
(специализация коммутирует с результантом; deg M + 1 обычных Q[x]-результантов
+ Лагранж). Шаблонизация UPoly не понадобилась.

Лог-часть переписана: сначала Трагер — рациональные корни бесквадратной
части R(t) = res(A − tS′, S) дают ВЫЧЕТЫ; каждый вычет r даёт одну
ГРУППИРОВАННУЮ логарифму r·log(gcd(A − rS′, S)) по всем полюсам с этим
вычетом (∫(2x+3)/(x²+3x+2) = log(x²+3x+2) одной группой — ось «качество
формы»). Остаток дроби уходит в старый путь расщепления. Урок: перебор
делителей для поиска рациональных корней РЕЗУЛЬТАНТА ломается о рост
коэффициентов (deg 10 уже даёт >2^40) — поиск вычетов сделан
best-effort: бюджет исчерпан → пропустить группировку, корректность не
страдает (старый путь находит те же корни по маленьким множителям).

Тесты: тождество специализации в случайных точках, оракул вычетов
(квадратичная часть R обязана равняться ∏(t − cᵢ) по построенным
вычетам), группированные фиксированные случаи. 71 тест зелёный.

## Сессия 2026-09-14: квадратичное кольцо без делений (пункт 12)

Профиль r0277: из 72 мс квадратичного цикла lift = 0.05 мс, ВСЁ —
в ModCPoly::gcd (Евклидов цикл над Q[t]/(c)[x]). Структурная

Фикс — замкнутые формы для deg c == 2 (модуль моничен: t² ≡ −p·t − q):
- mul: (a0+a1t)(b0+b1t) → m0 = a0b0 − q·a1b1, m1 = a0b1+a1b0 − p·a1b1

- inv: сопряжение t → −p − t; N = a0² − p·a0a1 + q·a1² ∈ Q (ненулевой
  для ненулевого элемента — кольцо ПОЛЕ по контракту неприводимости c),
  inv = conj/N — без Евклида.

Корректность быстрых путей: 30 существующих Python-оракул векторов
(t²−2, t²+t+1) проверяют mul/inv ПОБИТОВО (прошли без правок
оракула); новый property 8000 итераций на двух кольцах — быстрый
mul == generic reduce(a·b) на случайных дробных элементах,
a·inv(a) == 1, inv(inv(a)) == a, края (нуль, константы 3/7).

(dx = dt/t) к ∫R(t)/t·dt — рациональное ядро (Эрмит/Трагер/
сертификаты) переиспользуется ЦЕЛИКОМ в t-мире, ответ возвращается
подстановкой t → exp(x).

Реализация (ratint.cpp):
- substituteExpVar: Expr-rebuild с заменой exp(x) → t (символ '#e'
  недостижим из грамматики парсера — коллизий с пользовательскими
  символами нет); exp(k·x) с ЦЕЛЫМ k → t^k (покрывает exp(-2x),
  e^{3x}); голый x вне exp / дробный k / exp(x²) → honest отказ
  «mixes the variable outside exp(var)».
- integrateExpRational: подстановка → c.div(g, t) → ядро по t →
  substituteBack. Вызывается из integrateRational ТОЛЬКО после
  провала toRational по x — рациональные входы идут старым путём.
- Гейт двух уровней: ПЕРВИЧНЫЙ — рационализация dF и f в t-мире и
  ПОЛИНОМНАЛЬНОЕ сравнение (structural Expr-равенство слабее:
  канонизация не приводит 1 − t/(1+t) к 1/(1+t)); FALLBACK при
  иррациональных константах (atan-формы несут √(-D)) — точный
  структурный ROUND-TRIP substituteExpVar(F) == r.F + t-мирское
  тождество d/dt r.F = g/t уже доказано сертификатом ядра, цепное
  правило замыкает. Property-тест поймал этот пробел до коммита
  (4/3/(e^{2x}+e^x+1/3) — atan-форма с √3).

Показатели: 1/(e^x+1) → log(e^x) − log(1+e^x); 1/(e^x+e^{-x}) →
atan(e^x); e^x/(e^{2x}+1) → atan(e^x); exp(-2x) → −e^{-2x}/2 — все
PROVED. Honest: x·e^x, exp(x²), sin(x), log(exp(x)+1)+exp(x),
1/(e^{x/2}+1) (t^{1/2} нерационален).

Тесты (3 новых): фиксированные векторы (6 кейсов с точными строками
ответов), honest-отказы (6), property 120 случайных R(t) через

## Сессия 2026-09-19: второй лиувиллев этаж — рациональные функции от log (пункт 16)

t = log x, dt = dx/x: ∫R(log x)dx/x = ∫R(t)dt — рациональное ядро в

## Сессия 2026-09-26: радикальный этаж x^(p/q) (хвост пункта 17)

## Сессия 2026-10-01: C2-шаг 3b-1 — статическая специфичность

Кодеген сортирует правила ПО СПЕЦИФИЧНОСТИ паттерна перед

ПРОХОДИТ: специфичность выбирает (a+bx)^m, замена

PROVED. Оба сценария гейта сохранены как тесты: неверный

## Сессия 2026-10-03: C2-шаг 3b-3 — /-близнецы паттернов

Канонический DAG не хранит деление (a/b = a·b⁻¹, 1/u = u⁻¹) —
правила Rubi с явным «/» (Int[1/x_], Int[1/(a_+b_.*x_)]) были
НЕДОСТИЖИМЫ для матчера. Кодеген переписывает ПАТТЕРНЫ (замены не
трогаем — там «/» исполняется через div): rewriteDiv рекурсивно:
/[1, d] → ^[d, −1] (свёрнутый близнец), /[a, b] → *[a, ^[b, −1]].

ФЛАГМАН: ∫dx/x = log(x) — правило Int[1/x_] := Log[x] впервые
сработало: x^(−1) канонически = Pow[x,−1] = близнец 1/x_, матч,
замена Log[x], сертификат d(log x) = 1/x ✓. ТРИ тонкости заметны:
(а) trie ПОХУДЕЛ (14 узлов было 20): /-формы и ^-формы слились в
общие префиксы после переписывания — бонус канонизации; (б) правило
1/(a+b x) теперь тоже достижимо, но его замена несёт RemoveContent
— честный null (исполнение — остаток 3b); (в) BoundaryDeclines-

## Сессия 2026-10-04: C2-шаг 3b-4 — RemoveContent + полиномиальный гейт

Голова RemoveContent[u, x] в исполнителе замен: u как полином от x
(toRational), рациональный контент = gcd(числителей)/lcm(знамена

подынтегральное рациональны по var, перекрёстное умножение в Q(var)
(та же техника, что Tier-1 интегратора): d(log(1+2x)/4) =
(1/2)(1+2x)⁻¹ структурно ≠ 1/(2+4x), но равны в Q(x) — узловой
гейт такое ОТКАЗЫВАЛ, полиномиальный СЕРТИФИЦИРУЕТ. СТРУКТУРНАЯ
(фолбэк) — когда стороны нерациональны (дробные степени var):
точное тождество узлов, сильнейшая доступная проверка там.

Урок ступенчатости: первая попытка «только полиномиальный гейт»

Срез вырос файлом 1.1.1.2 (40 правил, всего 78). Четыре

## Сессия: пункт 30 — положительные степени (a+b x²)ⁿ, 120/120

Гипотеза заметки («замены правил используют голову Sum») ОПРОВЕРГНУТА
разведкой. Реальная блокировка оказалась в два слоя, оба в рантайме:

1. ПРАВИЛА УЖЕ БЫЛИ В ТАБЛИЦАХ. Срез 1.1.2.1 — полный upstream-файл
   (33 правила, сверено с github RuleBasedIntegration/Rubi), строки
   IGtQ/IntegerQ/ExpandIntegrand присутствовали в .inc; правила
   положительных степеней отказывали на УСЛОВИЯХ: предикат IntegerQ
   не был реализован в evalCondition → каскадная редукция
   x(a+bx²)ᵖ/(2p+1) + 2ap/(2p+1)·Int[(a+bx²)^(p−1)] /;
   GtQ[p,0] && (IntegerQ[4p]||IntegerQ[6p]) не могла сработать.
2. ТЕРМИНАЛЬНЫЕ УТИЛИ. Рекурсия сворачивается на (a+bx²)¹ → голый
   Add (канонизация фолдит ^1), и вход p=1 — тот же Add. Ни одного
   правила для голой суммы в upstream нет ВООБЩЕ (проверено клоном
   всего репозитория): Руби делает это УТИЛИТАМИ из «9.1 Integrand
   simplification rules» и функцией IntSum — Int[a_,x]:=a*x /;
   FreeQ[a,x]; Int[a_*u_,x]:=a*Int[u,x]; разбор суммы по слагаемым.

РЕШЕНИЕ (зеркалит архитектуру Руби — утилиты как КОД, не правила;
так же у нас уже устроены RemoveContent и Rt):
- evalCondition: +IntegerQ (рациональное со знаменателем 1);
- rubiApply: сертификат вынесен в certificateHolds(); после исчерпания
  цепочки правил (или отсутствия матча) — rubiLinearityFallback:
  Number → c·x; Mul с числовым фактором (канонический Mul держит его
  первым ребёнком) → c·rubiApply(rest); Add → почленно, ВСЕ слагаемые
  или честный отказ. Каждый собранный ответ проходит тот же
  сертификат.

Мотивация маршрута: у Руби предпочтительный путь при IGtQ[p,0] —
ExpandIntegrand (разложение в полином); мы сознательно берём ВТОРУЮ
ветвь цепочки (редукцию) — ExpandIntegrand остаётся неimpl, ветка
честно отказывает, цепочка падает на редукцию. Тот же сертифицированный
результат, компактная (нераскрытая) форма.

ИТОГ: руби-корпус 120/120 = 100% (медиана 53→70 мкс — цена каскада,
в 7 раз под лимитом §7 500 мкс), рациональный 500/500 без регрессии.

     если после глубокого сокращения `maxDeg < order`, `taylor` и `laurent`
     автоматически перезапускают вычисление с увеличенным запасом точности
     (`pad = 8 -> 16`).
   - Поддержаны:
     - обращение рядов `invSeries` и рациональные степени `powRatSeries` через
       биномиальный ряд $(1 + u)^{p/q}$ с проверкой делимости валуации `val * p % q == 0`;
     - композиция элементарных функций `exp`, `log`, `sqrt`, `sin`, `cos`, `tan`,
       `cot`, `sec`, `csc`, `sinh`, `cosh`, `tanh`, `coth`, `sech`, `csch`;
     - композиция обратных тригонометрических и гиперболических функций (`atan`,
       `asin`, `acos`, `atanh`, `asinh`, `acosh`) через почленное интегрирование
       производной аргумента $\int_0^t A'(\tau) F'(A(\tau))\,d\tau$;
     - фоллбэк `taylorByDiffFallback` через точное итерированное
       дифференцирование $f^{(k)}(x_0)/k!$ для гладких в точке $x_0$ выражений.
2. **Вычисление пределов `limit(Ctx&, Expr f, Expr var, Expr x0, Budget*)`**:
   - Возвращает `LimitResult` со статусами `Proved` (конечный предел в `value`),

     $\lim_{x\to 0} x^k \log x = 0$) выполняет перезапись произведения
     $A(x)\log B(x) = \frac{\log B(x)}{1/A(x)}$ и применяет ограниченное по глубине

### Сессия: символьная линейная алгебра и многомерный анализ `SymMatrix` (пункт 37 ЗАКРЫТ)

1. **Нормализация рациональных выражений `simplifyRationalExpr(Ctx&, Expr)` (`src/linalg/symmatrix.cpp`)**:
   - Рекурсивно сводит произвольное выражение `Expr` к формальной дроби
     `FormalFrac { Expr num; Expr den; }` из раскрытых через `c.expand`
     бесзнаменательных числителя и знаменателя (при совпадении знаменателей
     слагаемых в `Add` складывает числители напрямую без возведения знаменателя в
     квадрат).
   - Обеспечивает точное распознавание нуля (`isZeroSymbolic`) для многомерных
     рациональных выражений вида $\frac{x}{x+y} + \frac{y}{x+y} - 1 = 0$, а для
     одномерных рациональных функций из $\mathbb{Q}(x)$ выполняет полное
     сокращение на полиномиальный $\gcd(N(x), D(x))$ через `toRational`/`UPoly`.
2. **Класс `SymMatrix` и многомерный векторный анализ (`include/numkit/cas/linalg/symmatrix.hpp`, `src/linalg/symmatrix.cpp`)**:
   - Плотная матрица `SymMatrix` над интернированными узлами `Expr`: конструкторы
     `zeros`, `eye`, `diag`, `column`, `row`, операции `transpose`, `add`, `sub`,
     `mul`, `scale`, `trace`, почленные `expand`, `diff`, `subs` и строковое
     представление `toString` в синтаксисе MATLAB (`[a, b; c, d]`).
   - Операторы многомерного анализа:
     - `jacobian(c, funcs, vars)` — матрица Якоби $m \times n$ ($J_{i,j} = \partial f_i / \partial x_j$);
     - `gradient(c, f, vars)` — вектор-столбец градиента $n \times 1$;
     - `hessian(c, f, vars)` — симметричная матрица Гессе $n \times n$ с
       вычислением смешанных производных по верхнему треугольнику ($H_{j,i} = H_{i,j}$).
3. **Бесделительная линейная алгебра (Фаддеев–Леверье + точный Гаусс)**:
   - Рекурренция Фаддеева–Леверье `faddeevLeVerrier` строит коэффициенты
     характеристического многочлена $p(\lambda) = \det(\lambda I - A) = \sum_{j=0}^n c_j \lambda^j$
     и классическую союзную матрицу $\operatorname{adj}(A) = (-1)^{n-1} B_n$
     **без единого символьного деления** (только матричные умножения, след и
     деление на целое $k \in \{1, \dots, n\}$):
     - `charpoly(c, A, lambda)` — характеристический многочлен;
     - `adjugate(c, A)` — союзная матрица ($A \cdot \operatorname{adj}(A) = \det(A) I$);
     - `det(c, A)` — точный определитель $(-1)^n c_0$ (с прямыми формулами для
       $n \le 2$);
     - `inv(c, A)` — обратная матрица $\det(A)^{-1} \operatorname{adj}(A)$ с
       честным возвратом пустой матрицы при $\det(A) = 0$.
   - `linsolve(c, A, B)`:
     - Для квадратных систем ($m = n$) умножает $Y = \operatorname{adj}(A) \cdot B$
       в кольце полиномов и делит на $\det(A)$ один раз в конце — это избегает
       разбухания промежуточных дробей и ускоряет решение 3×3 символьных систем
       почти в **10 раз** (`6267 мс -> 672 мс` на 50 случайных системах над
       $\mathbb{Q}(x)$).
     - Для прямоугольных переопределённых систем ($m > n$) выполняет точное
       гауссово исключение с выбором ведущего элемента минимальной DAG-стоимости
       `c.exprCost`, проверкой совместности остаточных строк и обратной
       подстановкой.
4. **Трёхуровневые тесты (`tests/linalg/symmatrix_test.cpp`)**:
   - Фиксированные оракулы: матричная алгебра, якобиан полярных и 3D-координат,
     градиент и гессиан функции Розенброка в точке минимума $(1,1)$, определитель
     матрицы Вандермонда $3\times 3$, характеристический многочлен, обращение и
     `linsolve` (включая совместные и несовместные переопределённые системы).
   - Property-тесты: теорема Кэли–Гамильтона $p(A) = 0$, тождество союзной
     матрицы $A \cdot \operatorname{adj}(A) = \det(A) I$, формула Якоби для
     производной определителя $\frac{d}{dx}\det A(x) = \operatorname{tr}(\operatorname{adj}(A) A')$,
     обращение $A \cdot A^{-1} = I$ и round-trip `linsolve` на случайных
     матрицах над $\mathbb{Q}[x]$.
   - Граничные случаи: $1\times 1$, вырожденные матрицы, несовпадение размерностей
     и исчерпание `Budget`.

### Сессия: движок алгебраического и трансцендентного упрощения `simplify` (пункт 39 ЗАКРЫТ)

1. **Архитектура `simplify(Ctx&, Expr, Budget*)` и `Ctx::simplify(Expr)` (`include/numkit/cas/core/simplify.hpp`, `src/core/simplify.cpp`)**:
   - Итеративный выбор лучшего эквивалентного представителя по лексикографической
     метрике `(c.exprCost(cand), c.leafCount(cand))` (до 3 проходов до достижения
     неподвижной точки) среди 5 семейств кандидатов:

        (например, $1 + 2x + x^2 \to (1 + x)^2$).
2. **Трансцендентные и алгебраические правила в `rewriteBottomUp`**:
   - Пифагоровы, гиперболические и формулы двойного угла с произвольным
     символьным кофактором $A$:
     - $A \sin^2 u + A \cos^2 u \to A$ (например, $r\cos^2\theta + r\sin^2\theta \to r$),
     - $B \cos^2 u - B \sin^2 u \to B \cos(2u)$,
     - $B \cosh^2 u - B \sinh^2 u \to B$, $B \cosh^2 u + B \sinh^2 u \to B \cosh(2u)$,
     - $C - C \sin^2 u \to C \cos^2 u$, $C - C \cos^2 u \to C \sin^2 u$,
       $C + C \sinh^2 u \to C \cosh^2 u$, $-C + C \cosh^2 u \to C \sinh^2 u$,
     - $2k \sin u \cos u \to k \sin(2u)$, $\sin^k u \cos^{-k} u \to \tan^k u$,
       $\sinh^k u \cosh^{-k} u \to \tanh^k u$.
   - Чётность и нечётность на отрицательных аргументах ($\sin(-u) \to -\sin u$,
     $\cos(-u) \to \cos u$ и т.д.).
   - Обратные функции и радикальные композиции: $\exp(\log u) \to u$,
     $\log(\exp u) \to u$, $\sin(\arcsin u) \to u$, $\cos(\arcsin u) \to (1-u^2)^{1/2}$,
     $\sin(\arccos u) \to (1-u^2)^{1/2}$, $\cos(\arctan u) \to (1+u^2)^{-1/2}$,
     $\sin(\arctan u) \to u(1+u^2)^{-1/2}$, $\cosh(\operatorname{asinh} u) \to (1+u^2)^{1/2}$,
     $\sinh(\operatorname{acosh} u) \to (u^2-1)^{1/2}$.
   - Законы экспонент и логарифмов: $\exp(u)\exp(v) \to \exp(u+v)$,
     $\exp(u)^v \to \exp(u v)$, $\exp(k \log u) \to u^k$,
     $\log u \pm \log v \to \log(u v^{\pm 1})$ при уменьшении `exprCost`.

### Сессия: символьный решатель уравнений и нелинейных систем `solveSymbolic` / `solveSystem2` (пункт 41 ЗАКРЫТ)

1. **`solveSymbolic(Ctx&, Expr eqn, Expr var, Budget*)` (`include/numkit/cas/core/symsolve.hpp`, `src/core/symsolve.cpp`)**:
   - Многоуровневый символьный решатель уравнения `eqn == 0` относительно `var`:
     1) **Расщепление по множителям `Mul`**: если уравнение разложено на
        неотрицательные степени множителей, решает каждый множитель независимо.
     2) **Послойное обращение (`solveSingleOccurrence`)**: если `var` входит в
        выражение ровно один раз (`countVarOccurrences == 1`), обращает внешние
        операции `Add`, `Mul`, `Pow` (включая чётные степени с выдачей $\pm$ и
        показательные уравнения $b^{g(x)} = c$) и элементарные функции `exp`,
        `log`, `sqrt`, прямые и обратные тригонометрические и гиперболические
        функции.
     3) **Одномерные полиномы над $\mathbb{Q}[x]$**: раскладывает бесквадратную
        часть числителя через `factorOverQ` (Цассенхаус), возвращая точные
        рациональные корни для линейных факторов, квадратичные радикалы с выносом
        точных квадратных множителей из дискриминанта (`nthRootSymbolic`) для
        квадратичных факторов и канонические `RootOf`-атомы для вещественных
        корней неприводимых факторов степени $\ge 3$.
     4) **Параметрические символьные полиномы (`extractPolyCoeffsInVar` + `solvePolyCoeffs`)**:
        извлекает коэффициенты $c_0, \dots, c_d$ (содержащие произвольные
        символьные параметры $a, b, c, y$), отщепляет нулевые корни $x^m$,
        решает линейные, квадратные ($a x^2 + b x + c = 0 \to \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$),
        двучленные ($c_d x^d + c_0 = 0$) и биквадратные ($c_4 x^4 + c_2 x^2 + c_0 = 0$)
        уравнения.
     5) **Отсев ложных корней (`hasPoleAt`)**: каждый кандидат проверяется на
        отсутствие деления на ноль и логарифмических полюсов в исходном `eqn`
        (например, $(x^2 - 1)/(x - 1) = 0$ возвращает только $x = -1$).
2. **Нелинейные системы двух уравнений `solveSystem2(Ctx&, eq1, eq2, x, y, Budget*)`**:
   - Рассматривает числители $F(x, y) = \sum_{i=0}^m a_i(x) y^i$ и
     $G(x, y) = \sum_{j=0}^n b_j(x) y^j$ как полиномы от $y$ с коэффициентами из
     $\mathbb{Q}[x, \text{params}]$, строит матрицу Сильвестра
     $\operatorname{Sylv}_y(F, G)$ размера $(m+n)\times(m+n)$ в `SymMatrix` и
     вычисляет результант $R(x) = \det(\operatorname{Sylv}_y(F, G))$ через
     бесделительный алгоритм Фаддеева–Леверье.
   - Находит корни $x_i$ результанта через `solveSymbolic(c, R, x)`, подставляет
     $x = x_i$ в $F$ и $G$, находит $y_j$ и **сертифицирует** каждую пару
     $(x_i, y_j)$ прямой подстановкой в оба исходных уравнения
     (`simplify(subs(eq1)) == 0 && simplify(subs(eq2)) == 0`).
3. **CLI и тесты**:
   - В `apps/nkcas.cpp` добавлена команда `nkcas symsolve "<eqn>" <var>`.
   - Добавлен трёхуровневый тестовый набор `tests/core/symsolve_test.cpp` (6
     сьютов, включая параметрические полиномиальные и трансцендентные уравнения,
     пересечения окружности/параболы/гиперболы и параметрических прямых, а также
     property-тесты точного зануления невязки на 100 случайных квадратных
     уравнениях и 40 нелинейных системах).

### Сессия: сертифицированный решатель ОДУ 1-го и 2-го порядка `dsolve` (пункт 42 ЗАКРЫТ)

1. **ОДУ 1-го порядка `dsolve1` / `dsolve1IVP` (`include/numkit/cas/ode/dsolve.hpp`, `src/ode/dsolve.cpp`)**:
   - Каскад 4 точных аналитических классов для $y'(x) = \text{rhs}(x, y)$ с
     константой интегрирования $C_1$:
     1) **Прямая квадратура** $y' = f(x) \implies y(x) = \int f(x)\,dx + C_1$ через
        единый интегратор `integrate`.
     2) **Линейные ОДУ 1-го порядка** $y' = A(x) y + B(x)$: вычисляет
        первообразную $\int A(x)\,dx$, нормализует экспоненту от комбинации
        логарифмов (`expOfIntegral`: $\exp(a + c\log u) \to e^a u^c$), интегрирует
        $B(x) e^{-\int A(x)\,dx}$ либо (для постоянных $A$ и полиномиально-экспоненциально-тригонометрических
        правых частей $B(x)$) находит частное решение методом неопределённых
        коэффициентов.
     3) **Уравнения с разделяющимися переменными** $y' = g(x) h(y)$: раскладывает
        множители на зависящие от $x$ и от $y$, интегрирует $\int h(y)^{-1}\,dy = \int g(x)\,dx + C_1$
        и разрешает неявное уравнение относительно $y(x)$ через `solveSymbolic`.
     4) **Уравнения Бернулли** $y' = A(x) y + B(x) y^n$ ($n \neq 0, 1$): сводит
        подстановкой $u = y^{1-n}$ к линейному ОДУ $u' = (1-n)A(x)u + (1-n)B(x)$.
   - **`dsolve1IVP`**: подставляет начальное условие $y(x_0) = y_0$, находит $C_1$
     через `solveSymbolic` и сертифицирует как тождество ОДУ, так и $y(x_0) = y_0$.
2. **Линейные ОДУ 2-го порядка `dsolve2Linear` / `dsolve2LinearIVP`**:
   - Решает $a y''(x) + b y'(x) + d y(x) = f(x)$ с постоянными (возможно,
     символьными) коэффициентами:
     - **Однородный базис $(y_1, y_2)$** по знаку дискриминанта $\Delta = b^2 - 4ad$:
       апериодический режим ($\Delta > 0 \implies e^{r_1 x}, e^{r_2 x}$),
       критическое затухание ($\Delta = 0 \implies e^{r x}, x e^{r x}$) и
       колебательный вещественный базис ($\Delta < 0 \implies e^{\alpha x}\cos(\omega x), e^{\alpha x}\sin(\omega x)$).
     - **Частное решение $y_p(x)$**: строит дифференциальное замыкание правых частей
       $\{f(x), x f(x), x^2 f(x)\}$ под действием $\frac{d}{dx}$, отсеивает элементы
       ядра оператора $L[y] = a y'' + b y' + d y$ (автоматически обрабатывая
       простой и двукратный резонанс) и решает линейную систему относительно
       неопределённых коэффициентов через `SymMatrix` + `linsolve`; при выходе за
       класс квазиполиномов использует метод вариации постоянных через вронскиан
       $W(y_1, y_2) = y_1 y_2' - y_1' y_2$.
   - **`dsolve2LinearIVP`**: собирает $2\times 2$ систему для $(C_1, C_2)$ из
     условий $y(x_0) = y_0, y'(x_0) = y_0'$, решает её через `linsolve` и
     сертифицирует решение по ОДУ и обоим начальным условиям.
3. **Сертификат и тесты**:
   - Каждое решение обязано пройти символьную верификацию
     `simplify(y' - rhs(x, y)) == 0` / `simplify(a*y'' + b*y' + d*y - f) == 0`.
   - CLI `nkcas dsolve "<rhs(x,y)>" x` и 8 тестовых сьютов в
     `tests/ode/dsolve_test.cpp` (все 3 уровня, включая резонансные вынужденные

## 2026-10-21: Реализация пункта 46 — Прямое и обратное преобразования Лапласа (`laplace` / `ilaplace`)

Реализован третий пакет Эшелона 4 (пул `v0.4.0`):

1. **Прямое преобразование Лапласа (`include/numkit/cas/transform/laplace.hpp`, `src/transform/laplace.cpp`)**:
   - Функция `laplace(c, f, t, s, budget)` вычисляет одностороннее преобразование Лапласа $\mathcal{L}\{f(t)\}(s) = \int_0^\infty f(t) e^{-st}\,dt$:
     - константы и линейные комбинации (`Add`);
     - целые степени $t^n \implies n!/s^{n+1}$ ($n \in \mathbb{Z}_{\ge 0}$) и полуцелые степени $t^{k/2} \implies \Gamma(k/2 + 1)/s^{(k+2)/2}$ для нечётных $k \ge -1$ через точное произведение $(2m-1)!!\sqrt{\pi}/2^m$;
     - экспоненты $e^{\phi + at} \implies e^\phi/(s-a)$, тригонометрические $\sin(\phi + \omega t)$, $\cos(\phi + \omega t)$ и гиперболические $\sinh(\phi + at)$, $\cosh(\phi + at)$ функции (с раскрытием фазового сдвига $\phi$);
     - первая теорема сдвига $\mathcal{L}\{e^{at} g(t)\}(s) = G(s-a)$ и дифференцирование в частотной области $\mathcal{L}\{t^n g(t)\}(s) = (-1)^n \frac{d^n}{ds^n} G(s)$;
     - автоматическое понижение степеней и произведений `sin`/`cos`/`sinh`/`cosh` через формулы произведения в сумму (`reduceTrigProductsOnce`) и перевод оставшихся гиперболических комбинаций в экспоненты (`rewriteHypToExp`).

2. **Обратное преобразование Лапласа и круговой сертификат (`ilaplace`)**:
   - Функция `ilaplace(c, F, s, t, budget)` строит оригинал $f(t) = \mathcal{L}^{-1}\{F(s)\}(t)$ для строго правильных рациональных дробей ($\deg P < \deg Q$), полуцелых степеней $s^{-(2n+1)/2}$ и параметрических сдвинутых форм:
     - над $\mathbb{Q}[s]$ знаменатель раскладывается через `factorOverQ` на линейные множители $(s - r)^m$ и неприводимые квадратичные трёхчлены $(s^2 + bs + c)^m$ ($\Delta = b^2 - 4c$);
     - коэффициенты разложения на простейшие дроби находятся решением линейной системы $A\mathbf{x} = \mathbf{rhs}$ через `SymMatrix` и `linsolve`;
     - линейные полюса $(s-r)^{-k}$ дают $\frac{t^{k-1}}{(k-1)!} e^{rt}$; неприводимые квадратичные факторы при $\Delta < 0$ приводятся выделением полного квадрата $(s-\alpha)^2 + \omega^2$ ($\alpha = -b/2$, $\omega = \sqrt{-\Delta}/2$), причём кратные факторы $k \ge 2$ берутся точно через дифференцирование по частоте $\frac{2s+b}{(Q)^2} = -\frac{d}{ds}(Q^{-1})$ и рекуррентную формулу сдвига $I_k(u) = \frac{1}{2(k-1)\omega^2}\left(\frac{u}{Q^{k-1}} + (2k-3)I_{k-1}(u)\right)$; при $\Delta > 0$ ($s^2 - a^2$ с квадратичным иррациональным корнем) используются экспоненциальные/гиперболические формы;
     - для символьных параметров поддержаны общие формы $(s - a)^{-k}$ и $((s - \alpha)^2 + \beta)^{-k}$ ($k=1,2$).
   - **Круговой сертификат**: каждый кандидат $f(t)$ проходит обязательную проверку $\mathcal{L}\{f(t)\}(s) \equiv F(s)$ через `laplace` и `simplifyRationalExpr`/`simplify`; при несовпадении возвращается честный `Unevaluated`.
